# LLM Bot Setup - Free Gemini API Key

## 🤖 Upgrade Your Bot to Full AI Power

Your new LLM bot can understand ANY language (Urdu, English, etc) and have unlimited free-form conversations!

---

## ✅ Step 1: Get Free API Key

1. Go to: https://makersuite.google.com/app/apikey
2. Click **"Create API Key"**
3. Create new API key in default project
4. **Copy the key**

---

## ✅ Step 2: Set Environment Variable

### Option A: Windows Command Prompt
```cmd
setx GEMINI_API_KEY "your_api_key_here"
```

### Option B: PowerShell
```powershell
$env:GEMINI_API_KEY = "your_api_key_here"
```

### Option C: Create .env file in restaurant-bot folder
```
GEMINI_API_KEY=your_api_key_here
```

---

## ✅ Step 3: Start the LLM Bot

```powershell
cd restaurant-bot
node bot-llm.js
```

---

## 🎯 Now Your Bot Can:

✅ Understand Urdu, English, Hindi, or ANY language
✅ Have unlimited free-form conversations
✅ Remember conversation context
✅ Answer complex questions
✅ Engage naturally like ChatGPT
✅ No restrictions on topics

## 📝 Example Conversations:

**User (Urdu):** "السلام علیکم، مجھے پیتزا دینا ہے"
**Bot:** "وعلیکم السلام! پیتزا Rs. 800 میں دستیاب ہے۔ آپ کو کتنے چاہیے؟"

**User (English):** "Tell me about your restaurant and can you deliver to downtown?"
**Bot:** "We're open 10 AM to 11 PM and deliver all over the city! What would you like to order?"

**User (Mixed):** "Do you have any halal food?"
